# v0.5.0 验证记录

日期：2026-11-16。对应站内第 6 次更新；`src/releases.js` 与 `CHANGELOG.md` 同源。

## 变更与定位依据

- 更新弹窗默认只展开最新版本，并将焦点与滚动位置放回顶部。历史版本仍按序号倒序排列，可逐条展开。
- SortableJS 1.15.7（MIT）固定版本本地打包、完整性校验；附件支持拖动及键盘移动。统一序列允许已保存附件和新上传文件混排。
- 三个 provider 都校验 `mediaOrder` 是保留 ID 与本次上传索引的精确排列；无效输入在上传和写入前拒绝。前端不接受任意 `position`。
- 生产原 `publish_entry` 不更新位置，原测试 fixture 却更新，曾掩盖持久化缺失。本次迁移 `20261116112257_attachment_order.sql` 保留授权、对象、暂存限额和 CAS 校验，在一个事务内重排附件；两阶段更新避免立即唯一约束冲突。回滚函数见 `supabase/rollback/attachment_order.sql`。
- 原 `init()` 遇到临时网络错误后将 `mayRestore` 永久关闭，后续重试返回匿名；现允许网络错误与 429 重试，真实 401 仍清除界面并返回登录。
- 官方 `startAutoRefresh()` 会移除 SDK 的自动可见性监听。现显式管理前台、后台、online、pageshow 生命周期，退出后停止，销毁时清理。UI 用恢复代次阻止旧账号或旧请求覆盖新身份界面。
- 旧版公共服务组件 219,856 字节，每次刷新重下且单次 15 秒失败即停止。现本地组件最多尝试 3 次、每次 30 秒，模块入口失败有恢复按钮。只给 4 个固定版本公开 vendor 文件长期缓存；HTML、src、配置和私密请求保持 no-store，没有 Service Worker 或私密离线副本。此证据不能确定用户手机线路故障的唯一原因。
- 精简重复说明、页脚与弹窗文案；保留可见范围、隐私转换、上传限制等有用提醒。

## 验证

- 全部本地测试 **184 通过，0 失败，0 跳过**；含真实官方 Memos 二进制以及本项目实际发送的 Supabase SDK。
- SDK 故障模拟：后台 2 小时后 JWT 过期，认证先 503 后成功，前台恢复并换令牌，原 30 天绝对期限不延长。
- 生产 SQL 隔离验证完整执行并回滚，临时 Auth 用户剩余 0；覆盖位置伪造拒绝和稀疏暂存位置压缩。真实记录与账号未被替换。
- 生产 HTTP 探针 **19 项通过**，169 次请求、12 个微型 PNG、3 个随机记录；新增九图逆序和旧新混排读取验证。Storage、业务行和测试会话清理均完成；独立 SQL 查回本轮记录 0，临时函数退役后使用旧能力返回 410，数据库登录门保持开启。
- 探针使用可信管理员生成的 magiclink 会话；不等同于密码或 CAPTCHA 验收，不在公开仓库保存口令或令牌。
- 修改文件的界面静态检查 **0 FAIL、1 WARN**：警告是日历日期补零，保留合理。
- 桌面浏览器已实测鼠标拖动、键盘 End/Home、新旧附件混排、保存及刷新后顺序保留；1280×720 编辑器 clientHeight 与 scrollHeight 同为 575px，无内部滚动。
- 390px 手机与 768px 平板宽度无横向溢出；点赞、留言和收藏按钮均为 44px 高。更新弹窗验证 6 个版本中只展开 v0.5.0，初始滚动位置为 0；本地浏览器未记录控制台 error。触屏适配已实现，真实手机长按拖动仍需设备实测。

## 保留边界

此前共享且已被对方访问的同一文件 URL 在转悄悄话后仍可能命中旧 CDN 缓存。本次仍观察到旧 URL 为 200/HIT，新的 cacheNonce 与冷路径均为 400/DYNAMIC。没有宣称能收回已下载副本、已签发链接或旧缓存。

用户此前确认 v0.4.0 在当时线路下无需 VPN 可登录和加载图片；之后反馈手机刷新及长时间停留仍有问题。本版发布后，用户进一步确认手机关闭 VPN 后“刷新正常，保持登录”。该结果对应当时设备与线路；长时间后台恢复仍为模拟验证，不能用桌面与模拟结果替代真实手机的长时间停留测试。
