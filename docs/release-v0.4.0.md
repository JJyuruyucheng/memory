## 已共享图片的缓存边界

第一轮真实测试在“原共享 URL 改私密后立即不可读”断言失败，返回 200；该轮也已完整清理和退役。没有将这个失败改写为即时撤回成功。

第二轮明确区分三种请求，实际观察到：

| 请求 | 状态 | `cf-cache-status` | 结论 |
| --- | --- | --- | --- |
| 同一成员令牌、原已加载共享 URL | 200 | HIT | 既有缓存访问仍存在 |
| 同一图片、新 `cacheNonce` URL | 400 | DYNAMIC | 本次新鉴权访问被拒绝 |
| 同记录另一张此前未向该成员下载的图片 | 400 | DYNAMIC | 冷路径访问被拒绝 |

程序为私有文件新下载增加独特 URL 参数并使用 `no-store`，避免应用复用旧 HTTP 缓存授权。内存 Blob 仍在退出或失去可见范围时撤销。这**不能撤回**对方已保存的副本、浏览器/服务缓存或此前签发的有效下载链接；把共享记录改成悄悄话不能视为从未公开。界面也提示这一点。

依据：[Storage CDN](https://supabase.com/docs/guides/storage/cdn/fundamentals)、[Smart CDN 与撤权边界](https://supabase.com/docs/guides/storage/cdn/smart-cdn)、[下载与已签发链接](https://supabase.com/docs/guides/storage/serving/downloads)。Smart CDN 文档注明 Pro+；Free 环境中新 URL 的效果以上述实测为限。

## 本设备登录保持

客户端保存官方 Auth 会话，不保存密码。绝对期限为成功登录起 30 天，令牌刷新不延长期限；到期、退出或跨标签换号会清理旧身份的内容和媒体 URL。恢复时必须先经服务器 `getUser()` 校验，再加载受 RLS 保护的数据。存储被禁用时只保留当前标签页内存会话。

这是本设备的保存期限，不是 Supabase Free 服务端强制会话封顶。[官方会话文档](https://supabase.com/docs/guides/auth/sessions)说明服务端 timebox 属于 Pro+。清理浏览器数据、主动退出、服务端撤销会话或网络不可达，均可能使登录提前结束或暂时无法恢复；不会为此离线展示未验证的私密内容。
