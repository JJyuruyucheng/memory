# 安全边界与部署验收

此文档区分代码限制、本地官方 Memos 真实接口测试，以及尚须在目标主机验证的部署行为。2026-11-16 已运行官方 Memos 26.11.1 集成测试；这不等于完成生产部署或全面安全审计。

## 已实现的工程限制

- 构建模式仅接受 `demo` 或 `live`。真实模式要求显式指定 `spaces/<id>`；API 基址由构建生成为空字符串，只使用同源路径。URL 参数不能把 Pages 变为真实模式。
- Pages 工作流固定发布 `demo`，不读取真实账号、后台 Token 或空间密钥。`MEMORY_TARGET=pages` 时构建脚本也拒绝 `live`。
- 构建先对全部 `src` JavaScript 执行 `node --check`，核对入口、模块和样式依赖，再触碰现有输出。只复制首页、`src` 的 `.js`/`.css`、明确媒体/字体扩展名，以及唯一允许的 `assets/credits.json`；同时验证署名清单及其引用的媒体存在。隐藏文件、常见凭证命名和符号链接不允许进入产物；不复制 `.env`、`.git`、`deploy`、数据库或备份。
- 本地 QA 服务只监听 `127.0.0.1`，不静态提供整个仓库。只支持 GET/HEAD，拒绝目录穿越、隐藏路径、非白名单路径和符号链接，不提供目录列表。配置了内容类型、`nosniff`、禁缓存及仅允许同源连接的 CSP。
- 演示模式的身份切换仅用于体验，不是登录或权限隔离。演示数据不向真实 Memos 发送，不适合保存私人资料。

构建完整性测试使用新的系统临时目录，不覆盖正在验收的 `dist`。已检查错误语法、缺失入口和坏署名清单在覆盖旧产物之前失败，也检查普通 JSON 和 `.env` 不进入产物。

## 已执行的真实 Memos 与浏览器验证

证据为 [真实集成测试](../tests/memos-live.test.mjs)、[适配层测试](../tests/memos-provider.test.mjs) 和 [部署复现说明](deployment.md)。主任务已使用核对官方校验值的 Windows release，通过 `MEMOS_BINARY` 在独立临时数据库运行，而非只模拟后端返回。

- 初始化一个管理员和两个普通成员，核对 private access、关闭注册及三个空间成员；重复初始化不会重置账号。
- 两个成员分别通过官方 Connect `SignIn` 登录，使用原生会话 Cookie；`RefreshToken` 和 `SignOut` 接口在适配中保留。401 后刷新重试、凭证不进入应用 state，以及失败请求不被误报成功，另有独立适配层测试。
- 在指定 `SPACE` 创建记录，并通过另一成员账号读取保存的正文与媒体。错空间数据被适配层拒绝也有测试；这不替代对任意空间、任意原生 API 的完整权限审计。
- 项目适配层拒绝成员编辑对方记录或修改共同设置；管理员可维护记录和设置，并保留原作者。此处不把适配层的拒绝误称为已遍历所有服务端越权路径。
- PNG 上传后通过授权请求读取并转为 Blob URL；匿名猜测原始附件 URL 返回拒绝状态。未据此推定全部视频、缩略图和分享路径都已测试。
- 原生评论可保存并被另一成员刷新读取。回应和收藏分别使用原生心形/星形反应；取消回应不影响收藏。星形反应在共享空间内可见，不承诺私密收藏。
- 软删除、刷新后保留删除状态及恢复可用。删除是内容元数据更新，原生记录仍存在，没有部署自动 30 天销毁任务。
- 内容导出包含媒体 base64 与 MIME 类型，测试核对与原上传 PNG 一致，并确认没有口令或访问令牌。它不是完整服务器备份，也不代表已实现导入恢复。
- 浏览器中已实测演示发布、刷新后保留和评论。这验证的是演示界面交互；真实 Memos API 测试与演示浏览器检查分别记录，不混为两台设备上的生产验收。

## 目标部署尚待验证

1. Docker Compose 构建、Memos 数据卷及 nginx 的实际运行；容器配置和镜像 digest 已准备，不能仅凭文件存在认定部署成功。
2. 目标主机域名与 TLS 证书、同源代理、`X-Forwarded-Proto`、生产 Cookie 的 Secure/HttpOnly/SameSite 属性、CSRF 与退出后实际会话失效。不得把长期管理员 Token 填入静态 JavaScript。
3. 在目标环境与无痕窗口检查匿名列表、详情、评论、图片、视频、封面及分享路径；用非成员账号检查原生 API 的跨空间读取和修改，核对服务端授权。
4. 文件真实内容、数量、尺寸和配额的服务端独立校验，以及目标手机/浏览器的视频解码和内存使用。前端校验不是安全边界；手机照片元数据可能含定位信息。
5. 对目标数据库、媒体与配置执行一次完整离线备份及隔离恢复演练，核对恢复后的三个账号、记录、附件和权限。仅下载内容 JSON 不算后端备份验收。
6. 实际双设备访问、网络中断、同时编辑与长期会话行为；未实现 WebSocket 实时刷新、协同冲突合并或版本回滚。
7. 生产日志、报错、端口和静态目录不得暴露口令、会话、私密正文、数据卷或运维配置；升级后重新运行固定版本的测试。

## 隐私限制

正式内容预期只对空间内两个成员及有权维护的管理员开放。管理员与服务器所有者具有相应读取能力；未实现端到端加密。操作记录和审计日志的完整性、不可篡改性也未经过验证。

公开 Pages 已上线，且只发布虚构样例和本地演示交互。浏览器本地保存没有跨设备同步和自动灾难恢复保证。请使用导出功能了解格式与交互；不要把演示环境作为真实资料库。
