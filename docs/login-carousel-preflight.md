# 登录页照片轮播：本地验收

2026-11-17。当前线上版本仍为 v0.5.0，本次尚未发布；未创建新桶、未应用轮播迁移，也未放开任何现有图片权限。

## 已完成

- GitHub 核查后采用 Embla Carousel 8.6.0（MIT）；从 npm 固定版本获取 UMD，核对包完整性，本地文件和许可附 SHA-256 清单。没有新增公共 CDN 依赖。
- 登录页左侧左右轮播、圆点、暂停、6 秒自动播放；隐藏页面和减少动效偏好会暂停。手机显示紧凑照片区。没有照片或加载失败时保留原文案；照片加载不重绘密码表单或验证码。
- “我们与设置 → 登录页照片”：两位成员及管理员可新增、替换、移除、拖动或键盘排序，保存前预览。最多 8 张。
- 上传前验证实际 JPEG/PNG/WebP 文件头及像素上限，最长边缩至 1920px，重新编码 JPEG，使用随机文件名，不复制原始 EXIF。原始文件最多 15 MB，优化结果最多 5 MB。
- 新协议独立于私密记录：计划使用 private `login-photos` 桶，只给已发布精选图匿名读权，未发布图片仍隔离；两位成员写入由真实后端身份校验，CAS 防止覆盖并发更新。现有 `memory-media` 不更改。

## 本地证据

- 全部测试 **200 通过、0 失败、0 跳过**，包括官方 Memos 二进制、项目实际发送的 Supabase SDK、照片格式与编码边界，以及轮播照片 provider 的上传、清理、冲突和账号切换。
- Cloudflare 目标静态构建成功；尚未推送部署。
- 设计静态检查 **0 FAIL、1 WARN**，保留警告为日历日期补零。
- 浏览器使用已授权演示风景素材，实际完成 3 张上传、照片替换、Home 键排序、鼠标拖动排序、保存并切换另一位普通成员后再打开相同照片；原共同设置字段仍禁用。
- 实测照片轮播左右选择、暂停；照片正确解码，显示计数正确。390px 手机宽度无横向溢出，预览采用上下布局。
- 预览图片仅为本地演示风景图，不代表真实情侣照片已上传或公开。

## 尚需完成

用户此前要求所有记录和图片登录后可见。登录页轮播必须允许未登录访客读取，因此正在等待用户明确确认：是否接受“仅单独上传并发布的登录页照片公开”。不能把未答复视为同意。

确认后才创建专用桶、应用迁移、运行真实匿名/成员 HTTP 与 SQL 权限验证，再更新产品版本、同步修改日志并发布。真实 HTTP 测试不得删除或退役已有用户照片；初次空清单可使用精准限定的微型测试图片，结束后清理。删除不承诺撤回此前已经下载或缓存的公开副本。

迁移及协议详见 [登录页照片协议](login-photos.md)。
