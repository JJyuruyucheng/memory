# 朝夕 · 视觉方向与验收记录

设计抽样 seed：`2138525718`。方向：`Editorial greeting`。

页面围绕“打开两个人的生活记录本”组织：问候、相伴时间、自然日期分组与日常文字优先。可爱感来自柔和颜色、小型插画和明确的互动反馈；避免大面积爱心、装饰过密或把心情做成关系评分。

## 已确定的版式约束

- 奶白为页面底色；鼠尾草绿用于主要操作和一位作者的身份；淡粉用于另一位作者的身份。作者还要显示名字或头像，不能只依靠颜色区分。
- 桌面内容最大宽度约 `1100px`，采用 12 列：9 列时间线、3 列右侧信息轨。右轨承载共同天数、纪念日、月份概览等上下文。
- 时间线每条记录显示作者、发生日期、记录类型和可选心情；文字保持易读，图片真实比例优先，视频不自动播放。
- 手机上收为单列，并使用底部导航。发布入口易触达，编辑器与模态框应可滚动，底部留出安全区。
- 首页、记录详情、发布、日历、相册、统计、设置及管理员入口遵循同一套颜色、间距、按钮与状态语言。
- 演示提示需要持续可见；身份切换不能冒充真实登录。统计按记录计心情，未填写明确排除，不制造“感情分数”。
