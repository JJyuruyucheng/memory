# v0.7.0 说明与验证记录

日期：2026-11-18。对应站内第 9 次更新；修改日志与站内更新信息同源。

## 小标签分类

- 固定记录类型仍为随记、事件、悄悄话，不新增“感悟”或“总结”等固定类型。这些内容可填写为小标签。
- 列表从当前账号有权查看的已保存记录中汇总标签，去重后展示在类型筛选与作者、心情筛选之间；标签较多时换行排列。
- 标签默认单选，按完整标签精确匹配，不按片段模糊匹配。点击某个标签进行筛选，再点一次取消；“全部标签”恢复为不限制标签。
- 标签可与记录类型、作者、心情和搜索共同使用。点击记录上展示的小标签，也可直接按该标签筛选。
- 草稿、回收站记录，以及当前账号无权查看的悄悄话不会贡献标签分类。管理员能查看的记录仍遵循现有管理员权限。
- 已保存记录新增或修改标签后，分类随数据更新；删除某标签的最后一条可见记录，或从最后一条记录移除该标签后，分类中也不再展示该标签。
- 继续使用现有记录的 `tags` 字段，不需要数据库迁移，也不改变记录或附件的访问权限。

## 首页布局

- 移除列表上方的大块快捷记录入口和整行搜索，保留右上角“记录这一刻”按钮。
- 搜索调整为右上角的紧凑输入框与放大镜按钮，与记录按钮共同排列，为记录列表腾出首屏空间。
- 标签允许自然换行，窄屏时筛选区与顶部操作区适配可用宽度。
- 桌面中间记录区与右侧信息区各自滚动；右侧内容超出可用高度时，将指针移入右侧即可滚动查看，不带动中间记录区。手机继续使用自然整页布局。

## 时间与留言

- 记录及留言相关时间统一展示日期、小时和分钟；纪念日等只具有日期含义的字段继续只显示日期。
- 留言弹窗移除“在这段回忆里说两句”“还没有留言，写下你的感受吧”“想对 TA 说”等视觉上重复的引导文字，保留输入控件的可访问标签。

## 媒体预览与手机上传

- 图片预览提供放大、缩小、拖拽、鼠标滚轮缩放和手机双指缩放，并可适应画面或重置。
- 现有图片与视频可在预览中下载到本地；不新增公开附件入口，仍使用原有可见范围与文件权限。
- 缩放采用经 GitHub 核查的 MIT 开源组件 [Panzoom 4.6.2](https://github.com/timmywil/panzoom/tree/4.6.2)，固定版本本地打包，不依赖运行时公共 CDN。
- 手机上传输入声明为 `accept="image/*,video/*"`，不设置 `capture`，优先提供媒体选择。网页无法强制 Android 系统或浏览器一定打开某个相册；真实 Android 选择器的显示方式仍待设备确认。
- 以上改动不涉及数据库迁移或权限调整。

## 共同设置权限

- “我们与设置”页面中的全部现有功能向已登录的受邀账号开放，包括空间资料、纪念日、登录页照片以及页面现有操作，不再仅由管理员编辑空间资料和纪念日。
- 此调整需要后端授权同步支持，不只改变表单是否置灰。未登录访问继续受保护，也不开放注册。
- 开放范围限于共同设置，不扩大悄悄话的阅读范围，也不向普通成员开放“管理小屋”。仅专门发布的登录页照片继续允许公开展示；原相册与记录附件仍按原权限保护。
- 成员设置迁移 `20261118022125_member_settings` 已应用于正式 Supabase 项目；完整隔离 SQL 已执行并回滚。此为数据库授权证据，正式前端的真实账号页面验收另行记录。完整范围及旧 Memos 模式限制见 [共同设置的成员权限](shared-settings.md)。
